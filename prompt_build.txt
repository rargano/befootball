ฉันต้องการสร้างเว็บรายงานข่าวกีฬาฟุตบอลภาษาไทย โดยใช้สถาปัตยกรรมแบบ:

Frontend: Next.js  
Backend/API/Admin: Yii2  
Database: MySQL  
Queue/Cache: Redis  
Worker: Yii2 Console Command  
AI: ใช้สำหรับแปล สรุป และจัดหมวดหมู่ข่าว  
ภาษาเว็บหลัก: ภาษาไทย

เป้าหมายของระบบคือสร้างเว็บข่าวฟุตบอลที่ดึงข้อมูลจากหลายแหล่ง เช่น RSS, API, เว็บไซต์ข่าวที่อนุญาต, sports data API และ X API สำหรับข่าวลือ จากนั้นนำมาสรุป/แปลเป็นภาษาไทย พร้อมให้เครดิตและลิงก์กลับแหล่งต้นทางอย่างถูกต้อง

ห้ามออกแบบระบบให้ scrape ข้อมูลแบบผิดเงื่อนไขการใช้งานของเว็บต้นทาง โดยเฉพาะ X ให้ใช้ X API, embed หรือวิธีที่ได้รับอนุญาตเท่านั้น

## 3. Flow ข่าวทั่วไป

ออกแบบ flow ข่าวทั่วไปดังนี้:

1. Admin เพิ่ม source ข่าว เช่น RSS/API
2. Yii2 Console Worker ดึงข้อมูลจาก source
3. เก็บข้อมูลดิบลงตาราง raw_articles
4. ตรวจ duplicate ด้วย URL, hash และ similarity ของ title
5. แยกหมวดหมู่ข่าว เช่น transfer, injury, match report, preview, official
6. ส่งข้อมูลให้ AI แปลและสรุปภาษาไทย
7. AI ต้องห้ามแต่งข้อมูลเพิ่มจาก source
8. สร้าง draft article ในระบบ
9. Admin ตรวจและแก้ไข
10. Admin approve เพื่อ publish
11. Next.js ดึงข้อมูลผ่าน Yii2 API มาแสดงหน้าเว็บ
12. ทุกข่าวต้องมีเครดิตและลิงก์ต้นทาง

## 4. Flow ข่าวลือ Rumor

ออกแบบระบบ Rumor แยกจากข่าวปกติ เพราะข่าวลือมีความเสี่ยงสูงกว่า

แหล่งข่าวลืออาจมาจาก:

- X API
- นักข่าวสายตลาดซื้อขาย
- official club account
- league official account
- RSS/API ของเว็บข่าว
- manual input จาก admin

Flow:

1. Yii2 Console Worker ดึงโพสต์หรือข้อมูลจาก source ที่อนุญาต
2. เก็บข้อมูลดิบลง raw_social_posts
3. กรอง noise และโพสต์ที่ไม่เกี่ยวกับฟุตบอล
4. Extract entity เช่น team, player, league, manager
5. Group ข่าวลือที่พูดเรื่องเดียวกัน
6. คำนวณ confidence_score
7. คำนวณ heat_score
8. ให้ AI สรุปเป็นภาษาไทย
9. สถานะเริ่มต้นเป็น pending_review
10. Admin ตรวจ
11. Publish ไปหน้า /rumors

ข่าวลือต้องมีสถานะ:

- new
- monitoring
- heating_up
- reliable
- confirmed
- denied
- expired
- fake
- duplicate

ต้องแยกชัดเจนระหว่าง:

- confidence_score = ความน่าเชื่อถือ
- heat_score = ความมาแรง

ข่าวที่ดังมากไม่จำเป็นต้องจริงมาก

## 10. AI Prompt

ช่วยเขียน prompt สำหรับ AI 2 ชุด:

### Prompt 1: Article Translation

ใช้สำหรับแปลและสรุปข่าวทั่วไปเป็นภาษาไทย

กฎ:

- ห้ามแต่งข้อมูลเพิ่ม
- ห้ามเปลี่ยน fact
- ต้องแปลชื่อทีมและนักเตะอย่างระมัดระวัง
- ถ้าไม่แน่ใจชื่อภาษาไทย ให้คงภาษาอังกฤษไว้
- ต้องสร้าง title_th, summary_th, body_th
- ต้องระบุ source_credit_text
- ต้อง output เป็น JSON

### Prompt 2: Rumor Summary

ใช้สำหรับสรุปข่าวลือจาก X/API/social source

กฎ:

- ห้ามยืนยันข่าวที่ยังไม่มี official confirmation
- ต้องใช้คำว่า “มีรายงานว่า”, “ถูกเชื่อมโยง”, “ยังไม่ยืนยัน”
- ต้องแยก fact, rumor, opinion, joke
- ต้องระบุ risk_flags
- ต้องเสนอ confidence_score_suggestion
- ต้อง output เป็น JSON

## 12. Compliance

ระบบต้องมี compliance rule ดังนี้:

1. ทุกข่าวต้องมี original_url
2. ทุกข่าวต้องมี source_name
3. ทุกข่าวต้องมี source_credit_text
4. ห้าม publish ถ้าไม่มี source
5. ห้ามใช้รูปจาก source โดยไม่มีสิทธิ์
6. ห้ามดึง full article มาเผยแพร่ใหม่ถ้า source ไม่อนุญาต
7. X content ต้องใช้ผ่าน API/embed/วิธีที่อนุญาต
8. ข่าวลือต้องมี disclaimer
9. ข่าวลือจากแหล่งเดียวต้อง default เป็น monitoring
10. ข่าวที่มีความเสี่ยงสูงต้อง require human review

ช่วยเขียน RumorComplianceService และ ArticleComplianceService
